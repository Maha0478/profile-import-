# Profile import sketch, 2026-10-02

Superseded by `docs/profile-import-contract.md`. Kept for the record.

First idea from the kiosk pilot: the pasted profile replaces the saved one wholesale, so an administrator can "reset" kiosk in one step. Contradictions between allow and deny were to be resolved in favour of allow, because an administrator who lists a capability in allow clearly wants it. Validation of names against the catalog was left for later.
